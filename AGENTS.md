# Project instructions

Read README.md and docs/CARTOGRAPHY.md before implementation.
Keep source data, editorial content and rendering separate.
Never rename or reuse a released note ID. Assign this project its own stable deck/model IDs.
Do not copy wine-specific content or identifiers from the reference repository.
Normal builds must use pinned local geographic inputs, without downloading upstream data.
Record source, version, license and modifications for every geographic dataset.
Generated media must be content-addressed and bundled in the Anki package.
Do not present scaffold commands or unimplemented workflows as functional.
